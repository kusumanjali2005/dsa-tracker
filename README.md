# DSA 12-Week Tracker

A mobile-friendly, static DSA study tracker with a 12-week plan, daily tasks, 141 LeetCode problems, theory summaries, pattern-wise learning links, local progress tracking, reminders while open, and a weekly knowledge check + mock technical interview.

## Open it
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Use **Weeks** to open a topic and read the theory. Each topic has links to GeeksforGeeks DSA resources and LeetCode practice.
4. Use **Assess** at the end of every week. Choose that week, attempt the 3-question knowledge check, try the coding challenge, and answer the mock interview questions aloud.
5. Save your confidence rating and notes. Scores and progress are stored in that browser's local storage.

## Mobile use
For best results, host the folder as a static website (for example with GitHub Pages) and open the URL on your phone. You can then use the browser's **Add to Home Screen** option. Opening a local HTML file may restrict some browser features.

## Reminders and data
Notifications work only when browser permissions are granted and the page/browser supports them. Reliable notifications while the site is fully closed require additional push-notification infrastructure. Progress is saved locally in the browser and does not automatically sync between devices.
